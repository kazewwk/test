# 安卓直接导入

下载 `SHU_Cell_Biology_Android_20261010.apkg`，在手机“下载”中点开，选择 **AnkiDroid**，确认导入即可。图片已内置，无须解压、复制图片或设置媒体目录。

如果手机没有自动打开 AnkiDroid：打开 AnkiDroid 的牌组列表，点菜单 **导入**，选择刚下载的 `.apkg`。

导入后应显示“SHU 细胞生物学（含图）”及按章划分的子牌组。图片随包导入，断网也能显示。

这是牌组包，不是覆盖整份个人资料的 `collection.apkg`。使用兼容格式，不包含作者的复习进度。原生 Anki 后端已验证首次和重复导入；没有在实体安卓手机上测试。参考：[AnkiDroid 官方导入说明](https://docs.ankidroid.org/#importing)。
