## 新版导入

1. 在桌面 Anki 选择“文件 → 导入”，分别选择两份新版TXT。支持文件头的 Anki 2.1.54+ 会读取逐行牌组名称，并创建尚不存在的章节牌组。
2. 选择 **Basic／基础（单向）**，分隔符为 **Tab／制表符**，启用 HTML。预览应为4列：第1列正面、第2列背面、第3列标签、第4列牌组。第4列是牌组映射，不要当成普通笔记字段，也不要忽略。
3. 初次导入时，新卡自动归入“书名::第XX章 章节名”。笔记类型已有模板牌组覆盖时，先清除该覆盖，再按文件指定的牌组导入。
4. 手机使用可在桌面导入并同步后，在 AnkiDroid／AnkiMobile同步。这里未直接操作你的Anki客户端。

## 已经导入旧版时：移动卡片并保留进度

**重复导入TXT不会自动移动已经存在的卡片。** Anki会在原牌组中更新匹配的已有笔记，新版的逐行牌组列主要决定新卡位置。不要为分章而把已有卡全部删掉，也不要选择“重复笔记导入为新笔记”。

使用桌面 Anki 的“浏览”窗口，将旧卡按以下表格的章节条件筛选：

1. 先选中原来装这本书的旧牌组，再与表格给出的标签条件一起搜索。例如：`deck:"原来的生化大牌组名称" tag:目标::上海大学2027 tag:学科::生化 tag:章节::01`。保留旧牌组筛选，避免碰到其他来源的同标签卡。
2. 在**卡片模式**中全选筛选结果，选择“卡片 → 更改牌组”，新建或选择表格所列的完整子牌组名称，例如 `生物化学::第01章 生命的分子基础`。牌组名称中的 `::` 表示上下级。
3. 按各章重复移动。更改牌组沿用原卡片；不执行忘记、重置、删除或重新创建笔记。已有复习历史可保留。
4. 整理后，如需再导入新版，将重复匹配范围设为笔记类型，选择更新已有笔记；首字段没有改写，仍可匹配原笔记。若曾自行改写题面，先看导入预览，避免把改写后的原卡与新题面当成两张卡。
5. 检查书的总数与章节分布，然后同步。表中是文件里的完整卡量；若你曾主动删卡或只导入部分内容，自己的实际数量可能更少。
