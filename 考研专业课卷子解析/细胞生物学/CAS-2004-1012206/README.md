## 解析设置

这是文档识别与结构化结果，不是解题答案。模型输出未逐字人工校对，原件是公式、选项、题图和小字的最终依据；未由助手按学科知识改写或补题。

本卷使用 Tesla T4、原始VLM权重（float16、未做GGUF量化）＋vLLM；小模型后端为 onnx。
