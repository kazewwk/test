## 版本与模式

使用 **MinerU 4.1.5，Advanced（xhigh，官方最高公开质量档）**，OCR模式、图像分析开启。原始453物理页；双页合扫按实际中缝拆分并保留空白半页后，全量461个解析输入页；当前已解析5页。已完成卷附Markdown、结构化JSON、版面JSON、题图资产、原卷链接及运行参数。

IHB合订本已按科目边界从解析副本实际去除邻科文字；双页合扫按原文阅读顺序拆分，提供页码映射；所有原件保持不变。原件不足的分辨率不能靠解析模式恢复。

## 使用说明

- Markdown中的题图与公式对应的资产保存在每卷目录，下载时保留目录结构。
- 输出未逐字人工校对；计算条件、图、上下标、小字请对照原卷。不用识别错误替代原题。
- 原始资料的官方原卷/第三方扫描/第三方排印属性不因使用MinerU而改变。
- 兰州2003、2004的生化科目含30%有机化学，仍各计一套原科目。
