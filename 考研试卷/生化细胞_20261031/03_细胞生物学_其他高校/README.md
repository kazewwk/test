# 细胞生物学考研试题：其他院校资料包

本包下载并检查 **21 套按题目完整性计数的独立真题**，另附 **6 份回忆、残卷或版本存疑资料**。所有条目均有原PDF与文本提取/OCR。重复版本不增加套数。此包未含上海大学资料，也未将上海科技大学当作上海大学。

## 如何使用

优先阅读原PDF；纯文本用于搜索题目和定位考点。OCR没有逐字校对，尤其早年扫描、英文术语、上/下标、选项次序和实验图表可能出错。无答案条目未追加生成答案。第三方重新排版稿与原卷扫描已区分，题目完整不等于官方真实性已再次认证。

严格完整卷中，7套来自高校/招生官网，14套来自公开第三方存档。中科院2001年的A/B问答变体只算1套。中科院2002年虽然可见完整题型分值，但A/B标注不清，保守放入补充区。
