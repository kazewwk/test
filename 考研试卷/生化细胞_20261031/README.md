## 如何使用

1. 先看上大现行目录及历史题型资料。上大回忆题只用于辨认曾出现的考点。
2. 整套练习优先选较新的上科大2022—2024及国科大2020原卷，再按薄弱章节使用较早试卷。其他院校同名或同代码科目不代表与上大同卷、同范围。
3. PDF和图片是核对依据。文字层提取与OCR方便搜索，但分式、化学式、上下标、表格和图示可能识别不完整；公式与看图题须看原件。逐卷元数据区分文本提取、OCR及人工校对。
4. 绝大多数原卷没有答案。短篇自测的参考答案来自原网站，未作为官方标准答案，也未逐题学术复核。题目中的判断句和选项可能故意写错，不能直接当知识点背诵。
