# 生物学考研卡型模板

生化/分子/细胞的知识点大致落在七类里。每类给出：什么时候用、front/back 怎么写、JSONL 例子、常见写坏的样子。所有例子都用问答或术语卡，不用 cloze——填空卡只在最后一节单独说明。

目录：1 术语卡 · 2 对比卡 · 3 步骤卡 · 4 图卡 · 5 数值卡 · 6 机制/原因卡 · 7 方法/实验卡 · 8 框架卡（论述题骨架）· 9 什么时候才用 cloze · 10 一个知识点拆几张

---

## 1 术语卡（type: term）

用于名词解释。front 是术语，back 是**能拿满分的答案**：一句定义 + 一个关键特征/机制 + 一个例子或意义。考研名词解释通常 3～5 分，答案要有 2～3 个得分点，不是一个短语。

`reverse: true` 只给**考试会从定义反问术语**的条目开（填空题“……称为____”），以及容易和同类术语混的条目（同促/异促、同裂酶/同尾酶）。所有术语都反向会让卡量翻倍而收益很小。

```json
{"id":"sh-08-012","type":"term","deck":"生化::08 酶作用机制和酶活性调节","front":"别构酶（allosteric enzyme）","back":"含**别构部位**的调节酶：效应物与别构部位非共价结合→构象改变→活性部位亲和力/活性改变。\n- 多为寡聚体，v–[S] 曲线呈 **S 形**（正协同）\n- 不服从米氏方程\n- 例：ATCase 受 CTP 抑制、ATP 激活","extra":"朱圣庚 §8.5。易混：别构 vs 共价修饰（后者需酶催化、可逆磷酸化）","tags":["生化","第8章","核心","术语"],"reverse":true}
```

写坏的样子：back 只有一句话定义（名词解释拿不到满分）；front 同时放中英文和缩写（答案面才放英文）；一张卡塞两个术语。

## 2 对比卡（type: qa，back 用表格）

用于“比较 A 与 B”“区别”“异同”——上海大学 858 的名词解释经常这样出，简答也常考。front 点明比较的**维度**，back 用 Markdown 表格，行是维度、列是对象，格里只填关键词。

维度超过 6 行就拆成两张（结构维度一张、功能维度一张）。

```json
{"id":"sh-19-020","type":"qa","deck":"生化::19 氧化磷酸化","front":"从作用对象和后果比较：解偶联剂、氧化磷酸化抑制剂、电子传递抑制剂","back":"| | 解偶联剂 | 氧磷抑制剂 | 电子传递抑制剂 |\n|---|---|---|---|\n| 电子传递 | 继续甚至加快 | 停止 | 停止 |\n| ATP 合成 | 停止 | 停止 | 停止 |\n| 耗氧 | ↑ | ↓ | ↓ |\n| 机制 | 质子载体，消除梯度 | 堵 F0 质子通道 | 阻断某复合体 |\n| 代表 | DNP、产热蛋白 | 寡霉素 | 鱼藤酮、抗霉素 A、CN⁻ |","extra":"朱圣庚 §19.3。判断题常考“解偶联剂抑制电子传递”——错","tags":["生化","第19章","核心","对比"]}
```

对比卡之外，每个对象仍要有自己的术语卡；对比卡解决的是“区分”，不替代“定义”。

## 3 步骤卡（type: qa）

用于代谢途径、复制/转录/翻译过程、信号级联。**一步一张**：front 给上一步的产物（或“第 n 步”），问这一步的产物、酶、辅因子、能量变化；back 四项分开写。再配一张总览卡（front 问“写出 X 途径全部步骤”，back 是有序列表），用来练论述题的完整复述。

```json
{"id":"sh-17-031","type":"qa","deck":"生化::17 糖酵解","front":"糖酵解：1,3-二磷酸甘油酸 → ？（产物、酶、能量）","back":"→ **3-磷酸甘油酸**\n- 酶：磷酸甘油酸激酶（Mg²⁺）\n- 高能磷酸基转给 ADP → **ATP**（第一次底物水平磷酸化）\n- ΔG°′ ≈ −18.8 kJ/mol，体内接近平衡（可逆）","extra":"朱圣庚 §17.5 第 7 步","tags":["生化","第17章","核心","过程"]}
{"id":"sh-17-040","type":"qa","deck":"生化::17 糖酵解","front":"按顺序写出糖酵解 10 步的产物和酶（总览）","back":"1. 葡萄糖→G6P（己糖激酶，ATP）\n2. G6P→F6P（磷酸葡糖异构酶）\n3. F6P→F1,6BP（PFK-1，ATP）**限速**\n4. F1,6BP→DHAP+GAP（醛缩酶）\n5. DHAP⇌GAP（TIM）\n6. GAP→1,3-BPG（GAPDH，NAD⁺）\n7. 1,3-BPG→3-PG（PGK，ATP）\n8. 3-PG→2-PG（变位酶）\n9. 2-PG→PEP（烯醇化酶）\n10. PEP→丙酮酸（PK，ATP）","extra":"三个不可逆步：1、3、10","tags":["生化","第17章","核心","过程","总览"]}
```

不要把 10 步写成 10 张 cloze（“第 3 步的酶是 {{c1::PFK-1}}”）：填空只能靠句型认出来，换个问法就不会。

## 4 图卡（type: image）

用于结构（血红素、tRNA 三叶草、核小体）、通路图、曲线（氧合曲线、双倒数图）、实验装置。`image` 放正面，front 对图提问；back 回答。图来自 `*制卡/NN_*/images/`，文件名写进 `image` 字段即可，构建脚本会打包。

三种问法，按掌握程度递进：
- 认图：“这是什么结构/哪条途径？”
- 读图：“图中 A/B 处发生什么？为什么曲线右移？”
- 默画：front 只有文字（“画出 tRNA 三叶草并标出四个臂和反密码子位置”），图放 `back_image` 作为答案。

```json
{"id":"sh-04-018","type":"image","deck":"生化::04 蛋白质的生物学功能","image":"part_003_9f1c…e2.jpg","front":"图中 Hb 的氧合曲线相对 Mb 为什么是 S 形？标出 P50 并说明 H⁺、CO₂、BPG 使曲线向哪移","back":"- S 形 = **正协同**：第一个 O₂ 结合使 T→R，后续亚基亲和力↑（Hill 系数 2.8）\n- P50 ≈ 3.5 kPa（Mb 0.27 kPa）\n- H⁺↑、CO₂↑、BPG↑ → 曲线**右移**（亲和力↓，利于组织放氧）","extra":"朱圣庚 图4-x；Bohr 效应","tags":["生化","第4章","核心","图"]}
```

图里的标注如果直接给出了答案，用 `back_image` 放原图、front 用文字描述或裁过的图。

## 5 数值卡（type: qa）

用于常数、参数、计量（α 螺旋 3.6 残基/圈、软脂酸 106 ATP、Tm 公式）。front 问**带单位和条件**的问题，back 给数值 + 单位 + 一句“怎么来的”（可推导的数值记推导比记结果牢）。

成组的数值（A/B/Z-DNA 参数、核糖体组分）做一张表格卡 + 每格一张单值卡；只做表格卡会导致“看着表能背，单问一个答不出”。

```json
{"id":"sh-24-055","type":"qa","deck":"生化::24 脂质的代谢","front":"1 分子软脂酸（16:0）彻底氧化净生成多少 ATP？分项列出","back":"**106 ATP**（新口径 2.5/1.5）\n- 7 轮 β 氧化：7 FADH₂×1.5 + 7 NADH×2.5 = 28\n- 8 乙酰-CoA×10 = 80\n- 减活化消耗 2（ATP→AMP+PPi）\n- 28+80−2 = 106","extra":"旧口径（3/2）为 129；答题注明口径。硬脂酸 120、油酸 118.5","tags":["生化","第24章","核心","数值","计算"]}
```

## 6 机制/原因卡（type: qa）

用于“为什么”“如何保证”“意义是什么”——简答题的主体。front 用为什么/如何/说明，back 按因果链 2～4 条。这类卡是“理解”的载体，Dunlosky 的精细询问（elaborative interrogation）就是让学习者回答“为什么这是对的”。

```json
{"id":"sh-30-044","type":"qa","deck":"生化::30 DNA 的复制和修复","front":"大肠杆菌错配修复如何区分母链与新生链？","back":"- Dam 甲基化酶使 GATC 中 A 的 N6 甲基化，**复制后新链有数分钟未甲基化**\n- MutS 识别错配 → MutL 偶联 → **MutH 切未甲基化链**的 GATC\n- 外切 → pol III 填补 → 连接酶\n- 结论：保留母链、修正子链","extra":"朱圣庚 §30.2；真核无 Dam，靠链切口区分","tags":["生化","第30章","核心","机制"]}
```

## 7 方法/实验卡（type: qa）

用于技术原理（SDS-PAGE、Southern、Sanger、ChIP）和经典实验（Meselson–Stahl、Hershey–Chase、Anfinsen）。

- 技术卡模板：front “X 的原理和用途”；back 固定四行：依据（分离/检测依据什么性质）→ 步骤要点 → 用途 → 注意点/局限。
- 经典实验卡：front 问**结论如何得出**（“Meselson–Stahl 如何证明半保留复制？”），back 写材料/标记 → 处理 → 现象 → 结论；再配一张“给现象反推结论”的卡（front 描述条带结果，问支持哪种模型）。

```json
{"id":"sh-05-022","type":"qa","deck":"生化::05 蛋白质的性质、分离纯化和鉴定","front":"SDS-PAGE 的分离依据、步骤要点、用途和局限","back":"- 依据：SDS 按 **1.4 g/g** 结合蛋白，电荷密度趋同、链伸展 → 迁移率只取决于**分子量**\n- 步骤：SDS+β-巯基乙醇煮沸变性 → 聚丙烯酰胺凝胶电泳 → 考马斯亮蓝/银染 → 与标准蛋白 lgMr 对比\n- 用途：测亚基分子量、判断纯度、推断亚基组成（±巯基乙醇对比）\n- 局限：测的是亚基不是天然分子；糖蛋白偏差；误差约 10%","extra":"朱圣庚 §5.3；858 几乎年年考分离纯化","tags":["生化","第5章","核心","方法"]}
```

## 8 框架卡（论述题骨架）

论述题 10～20 分，考的是能否在 10 分钟内组织出完整要点。每章挑 2～4 个高频论述题做框架卡：front 是题目原话，back 是 5～8 条要点标题（不展开，每条后括号写展开时要带的关键词）。复习时口述展开。

```json
{"id":"sh-28-003","type":"qa","deck":"生化::28 新陈代谢的调节控制","front":"【论述】饥饿时机体三大营养物质代谢如何变化？（答题框架）","back":"1. 激素背景：胰岛素↓、胰高血糖素↑、皮质醇↑\n2. 糖：肝糖原 12～24 h 耗尽 → 糖异生↑（乳酸、甘油、生糖氨基酸）；脑仍优先用糖\n3. 脂：脂肪动员↑（HSL）→ β 氧化↑ → 酮体↑，脑逐渐改用酮体\n4. 蛋白：肌蛋白分解供糖异生，后期减少以保存蛋白\n5. 时间线：早期（糖原）→ 中期（糖异生+酮体）→ 长期（酮体为主，蛋白分解↓）\n6. 关键酶：PEPCK、F-1,6-BPase↑，PFK、PK↓；HMG-CoA 合酶↑","extra":"朱圣庚 §28.4；Lehninger 第23章进食/禁食表更系统","tags":["生化","第28章","核心","论述框架"]}
```

## 9 什么时候才用 cloze

只有两种情形值得用，而且总量控制在 5% 以内（校验脚本会卡）：

1. **必须按位置记的序列**：共有序列（TATAAT、Kozak、SD）、短肽序列（谷胱甘肽、脑啡肽）、碱基配对规则。每个位置一个 c 编号，这样一条笔记生成几张卡，每张只遮一处。
2. **公式中的一个量**：`Tm = 69.3 + {{c1::0.41}}×(G+C)%`。

不要用 cloze 做定义（“{{c1::别构酶}}是含别构部位的调节酶”）——遮住主语之后句子本身就是提示，复习变成句型识别；也不要把一段教材原文挖 5 个空。把它改成问句：问“含别构部位、S 形曲线的调节酶叫什么？”和“别构酶的三个特征是什么？”两张。

## 10 一个知识点拆几张

以“己糖激酶 vs 葡糖激酶”为例，一个考点通常需要 3～4 张从不同角度问的卡，而不是 1 张大卡：

| 角度 | 卡 |
|---|---|
| 术语 | 葡糖激酶是什么（肝、Km 高、不受 G6P 抑制）→ term |
| 对比 | 两者 Km、组织、调节、生理意义四行表 → qa 表格 |
| 数值 | 己糖激酶 Km 0.1 mmol/L，葡糖激酶 5～10 mmol/L，血糖 4～5 mmol/L → qa |
| 原因 | 为什么葡糖激酶 Km 高对肝有意义？（血糖高时才大量摄取）→ qa 机制 |

反过来，一张卡问“说出己糖激酶和葡糖激酶的所有区别和意义”虽然信息全，但复习时要么全对要么全错，间隔算法没法区分你哪一部分不熟。

### 卡量换算（估算用）

| 教材内容 | 大致卡数 |
|---|---|
| 一个名词解释级术语 | 1（+1 反向，仅高频） |
| 一张比较表（≤6 行） | 1 表格卡 + 每行 0～1 单值卡 |
| 一条 n 步途径 | n 步骤卡 + 1 总览 + 1～2 调节卡 |
| 一幅结构图 | 1～3（认图/读图/默画） |
| 一组数值（表格） | 1 表格卡 + 每格 1 单值卡（只做会单独考的格） |
| 一道课后简答题 | 1～3 |
| 一道论述题 | 1 框架卡 + 要点中的新事实各 1 |
