# Anki 设置：考研场景

生成 .apkg 之后，告诉使用者这几件事。依据是 Anki 官方手册（deck-options、studying、filtered-decks、leeches）和 FSRS 作者/维护者的说明；没有依据的地方标了“经验”。

## 导入

1. Anki ≥ 23.10（FSRS 内置）。双击 `.apkg` 或 File → Import。再次导入同一批（同 id）卡会更新内容、保留进度；导入对话框里把 “Update notes” 设为 “Always”。
2. 不要把文件命名为 `collection.apkg`。
3. 用 TSV 导入时：File → Import 选 .txt，字段分隔符会按头部自动识别；图片要自己复制到 `collection.media/`（Tools → Check Media 可以核对）。

## 牌组结构

- 一个学科一个顶层牌组（生化、分子、细胞），章节是子牌组 `生化::17 糖酵解`。日常**在顶层牌组复习**，让各章混排——交错练习比按章分块练习效果好得多（Rohrer & Taylor 2007；见 principles.md 第 6 节）。
- 子牌组只用于临时聚焦（刚学完一章想先过一遍）和查进度。
- 牌组选项（preset）按学科设一个即可；只有当某批卡明显难度不同（例如纯数值卡）才分 preset。

## FSRS

- 牌组选项底部开启 FSRS（全局生效）。学习步骤填 `10m 30m`（或留空交给 FSRS）；不要用 ≥1d 的步骤——它会固定第一个间隔，让算法失去调节空间（手册；Expertium）。
- **Desired retention（期望保留率）**：
  - 默认 0.90。手册：超过 0.90 工作量迅速上升，>0.97 可能不堪重负；FSRS 文档：0.70–0.97 都合理。
  - 考研 2～3 个月备考：0.90 起步；如果每天复习量能承受，考前 2～3 周升到 0.93～0.95 并勾选 “Reschedule cards on change”——不要一开始就 0.95（经验，Anki 论坛考前讨论）。
  - 检验：Stats 里的真实保留率应接近期望值；复习卡 Again 比例 5～20% 为正常（手册）。偏差大 → 点 Optimize、处理 leech、检查是不是在把“答对一半”按成 Good。
- **Optimize**：复习记录达到几百条后点 FSRS parameters → Optimize，每月一次足够；不要手改参数或抄别人的。
- **Maximum interval**：考前把它设成到考试的天数的一半左右（例：剩 90 天 → 45 天），保证每张卡考前至少再见一次。代价是复习量上升（Expertium 估计从 36500→365 天约 +50～60%），所以只在考前 2～3 个月做（经验）。
- **Hard 是“答对但慢”**，不是“没记住”。忘了按 Again，否则间隔会虚高、考前掉链子。

## 每日量

- 手册经验：每天 20 张新卡 ≈ 每天 200 张复习。自制卡起步 20～40 新卡/天（社区）。按制卡建议的卡数倒推：3600 张生化卡 75 天 → 约 50 新卡/天 → 复习高峰约 400～500/天，每天 1.5～2 小时。撑不住就退到精简档，而不是降低期望保留率。
- 复习上限设高（如 9999），避免因为上限把到期卡推到明天堆成积压（AnKing 等医学生做法）。
- 有积压时先停新卡（新卡/天设 0），积压清完再恢复。
- New card sort order 用 “Card type, then order gathered” 可保证术语卡正向先于反向出现；是否 bury siblings 手册没有建议，默认即可。

## 考前两周

- 用 **Custom Study / Filtered deck** 做针对性突击，不改原调度：
  - Tools → Create Filtered Deck，搜索 `deck:生化 tag:核心 prop:lapses>=3` 抓反复错的卡；`rated:14:1` 抓两周内按过 Again 的；`tag:第5章 tag:方法` 抓某题型。
  - 取消勾选 “Reschedule cards based on my answers” → 预览模式，复习完原样回家，不打乱 FSRS。
  - “Review ahead（提前复习）”只用一两次，反复用会把成熟卡推远。
- 框架卡（论述题骨架）在考前两周单独建一个 filtered deck（`tag:论述框架`）每天过一遍。

## Leech

- 默认 lapse 8 次自动标 `leech` 并暂停。每周看一次 `tag:leech`：多半是卡写坏了（一卡多事实、问句含糊、和另一张卡干扰）。处理顺序：改写 → 拆分 → 加对比卡消歧 → 实在不值得就删。
- 把阈值降到 6 能更早发现问题卡（AnKing 做法，经验）。

## 复习时的动作

- 看到问题先**口述或默写**完整答案，再翻面对照粗体关键词；只在心里“觉得会”就点 Good 是流畅度错觉（Koriat & Bjork 2005）。
- 图卡的“默画”题真的拿笔画；步骤卡说出酶和辅因子再翻面。
- 对比表格卡：先把表格空着在脑子里填完再翻。
