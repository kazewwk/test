# 生物考研 Anki 制卡

把教材章节变成 Anki 卡片，让复习者在考场上能**写出**答案，而不是在 Anki 里**认出**答案。整个流程围绕一个判断：这张卡在复习时会不会强迫检索一个考试要用的事实。

## 这个技能解决什么问题

自动生成的卡片常见的失败方式：整段教材挖空做 cloze、一张卡塞一段话、是非题、问句含糊不知道该答什么、没有图、没有来源、列表卡每次都“想起 5 个漏 2 个”。这些卡复习起来很顺（因为在认句子），考试时答不出来。本技能的写法、校验脚本和打包脚本都是为了避开这些坑。使用者明确**不喜欢 cloze**，校验器默认把 cloze 卡限制在 5% 以内。

## 输入与输出

**输入**（用户给的，缺什么就问）：
- 教材章节 Markdown（本仓库里是 `生化制卡/NN_第N章_*/NN_*.md`、`分子制卡/...`；其他项目可以是任意章节文本）。
- 目标卡数和权重：本仓库 `生化制卡/制卡建议.md`、`分子制卡/制卡建议.md` 里每章都有“推荐”张数、制卡方式提示和**教材错误清单**；按它来。没有建议文件时，自己按 `references/card-patterns.md` 末尾的换算表估。
- 考试口径（哪所学校、哪本教材为准、题型）。本仓库使用者的目标是上海大学 071000 生物学：初试 858 生物化学（朱圣庚）+ 626 细胞生物学，复试笔试分子生物学；名词解释常以“比较 A 与 B”出，蛋白质分离纯化年年考，60 道客观题要求全书覆盖。

**输出**（放在章节文件夹下的 `anki/`）：
- `cards.jsonl`：卡片规范，一行一张，人可读可改，是**唯一需要维护的源文件**。
- `<学科>_<章>.apkg`：含图片、笔记类型、样式，双击导入。
- `tsv/*.txt`：文本导入备选（每种笔记类型一个文件）。
- 终端汇报：各类型张数、cloze 比例、校验警告、与目标数的差距、Anki 设置要点。

## 工作流

### 1 读懂章节和要求

读整章正文（不是只读标题），同时读该章在 `制卡建议.md` 里的条目：推荐张数、哪类知识占大头、制卡提示、教材错误。制卡建议里标出的错误（例如“羊毛固醇 C27 应为 C30”“Kozak −4/+1 应为 −3/+4”）在卡上要写**正确值**，并在 `extra` 注明教材原文有误——否则会把错误背进去。

章节里用 `<!-- EN-BEGIN -->` / `<!-- W-BEGIN -->` 等标记包着的插入内容（Lehninger、Campbell、Watson）默认不制卡，只有建议文件点名“值得补”的点才做（如转酮酶辅酶 TPP、四种添补反应）。

### 2 盘点知识原子

按七类过一遍章节，列出可独立回忆的点：概念/定义、结构（要会画会认）、过程/步骤、数值、比较/区分、调节机制、方法/实验。制卡建议里已经给了每类的数量和例子，照着盘点，不要重新发明分类。

盘点时同时决定**跳过什么**：建议文件的“可跳过或降级”列表，加上以下常规排除——人名年份（除经典实验）、商品名、仪器参数、教材里一句带过的新进展、目标院校大纲明确不含的节。精简档就是只保留“名词解释会出 / 填空会出 / 论述骨架”三类。

### 3 写卡

读 `references/card-patterns.md`（卡型模板，含 JSONL 示例）；原则有疑问时查 `references/principles.md`（每条带依据）。要点：

- **问答卡为主**。术语用 `term` 卡（答案三要素：定义 + 关键特征 + 例/意义），只给会被反问的术语开 `reverse`。
- **一卡一事实**。答案口述超过 10 秒就拆。一个考点通常 3～4 张卡从不同角度问（定义/对比/数值/原因），不是 1 张大卡。
- **问句写明答案形状**：答一个数、一个酶、三条理由还是一张表。用考研答题句式（“X 是什么”“X 的机制”“从 A、B、C 比较 X 与 Y”）。不出是非题。
- **过程 = 步骤卡 + 总览卡**；**比较 = 表格卡（≤6 行）+ 各成员术语卡**；**数值 = 带单位带条件 + 一句推导**；**机制 = 因果链**；**方法 = 依据/步骤/用途/局限四行**；**图 = 认图/读图/默画**。
- **列表**：有顺序按顺序，无顺序改成“实例→类别”卡 + 计数卡；>7 项必拆。
- **框架卡**：每章 2～4 道高频论述题，front 是题目，back 是 5～8 条要点标题。
- **cloze 只用于固定序列和公式中的一个量**（共有序列、短肽、Tm 公式系数），≤5%。想写 cloze 时先试着改成问句或步骤卡。
- 每张卡 `extra` 写来源（章节/图号）、口径差异、易混提醒；`tags` 至少含学科、`第N章`、权重（核心/重要/一般）、卡型。
- 相似概念放同一牌组混排，不另开小牌组。牌组名 `学科::NN 章名`。
- 图片：从章节文件夹的 `images/` 挑，`image` 字段只写文件名；图上带答案的放 `back_image`。

写卡的量：按推荐张数 ±15%。写完先自检一遍：随机抽 10 张，想象在考场上被问到——这张卡练的东西能直接写上卷子吗？不能就改。

### 4 校验

```bash
python3 <skill>/scripts/validate_cards.py <章节>/anki/cards.jsonl --media-dir <章节>/images --target <推荐张数>
```

错误（E）必须清零：缺字段、id 重复、cloze 超 5%、图片不存在、非 cloze 卡含 `{{c1::}}`。警告（W）逐条看：是非题改问句；过长的拆；近似重复的换角度；缺章节标签/来源的补上。不要用 `--max-cloze` 调高上限来通过校验——那是在绕开这个技能存在的理由。

### 5 打包

```bash
python3 <skill>/scripts/build_anki.py <章节>/anki/cards.jsonl \
  --out <章节>/anki/<学科>_<NN>.apkg --media-dir <章节>/images --tsv-dir <章节>/anki/tsv
```

需要 `pip install genanki`。多章合并成一个 .apkg 时把多个 jsonl 一起传入，牌组按每张卡的 `deck` 分。`id` 稳定则重复导入只更新不新建——改卡后重新打包、再导入即可。

### 6 汇报

告诉用户：张数（按类型）、cloze 比例、与目标的差距和原因、校验剩余警告、跳过了哪些内容、教材错误如何处理；然后给 `references/anki-settings.md` 里的导入与设置要点（FSRS 开启、期望保留率 0.90、最大间隔设为考前天数一半、每天新卡量、复习时先口述再翻面）。不要只说“已生成”。

## 卡片规范（JSONL）

一行一张，字段见 `scripts/cardspec.py` 开头的说明。最小例子：

```json
{"id":"sh-18-007","type":"qa","deck":"生化::18 柠檬酸循环","front":"柠檬酸循环中唯一的膜结合酶是哪个？它的辅基和产物是什么？","back":"**琥珀酸脱氢酶**（复合体 II）\n- 嵌在线粒体内膜\n- 辅基 FAD（共价结合）+ 3 个 Fe-S 中心\n- 琥珀酸 → 延胡索酸，FAD → FADH₂（1.5 ATP）","extra":"朱圣庚 §18.2 第 6 步；其余 7 个酶在基质","tags":["生化","第18章","核心","过程"]}
```

`front/back/extra` 支持轻量 Markdown：`**粗体**`、换行、`| 表格 |`、`1.` 有序列表、`-` 无序列表、`$公式$`（转 MathJax）、`^上标`、`~下标~`。

## 文件

- `scripts/validate_cards.py` 校验；`scripts/build_anki.py` 打包；`scripts/cardspec.py` 规范与 Markdown 转换（两脚本共用）。
- `references/card-patterns.md` 七类卡型模板与 JSONL 示例、cloze 边界、卡量换算——写卡前读。
- `references/principles.md` 每条写法原则的证据（Dunlosky 2013、Roediger & Karpicke、Rohrer、Wozniak 20 规则、Nielsen、Matuschak）——拿不准时查。
- `references/anki-settings.md` 导入、FSRS、每日量、考前 filtered deck、leech——汇报时用。
- `references/anki-format.md` Anki 文本导入与 .apkg/genanki 的官方规则——改脚本或排查导入失败时查。

## 常见情况

- **用户只给一个知识点或一段笔记**：同样走 2～5 步，不需要章节文件；`deck` 按用户的科目命名。
- **用户要“先出 20 张看看”**：挑该章最高频的点（名词解释 + 对比 + 一张图 + 一个数值 + 一个框架），覆盖各卡型，让用户看到风格再铺开。
- **用户要改已有卡**：直接改 `cards.jsonl`，重新校验打包；保持 `id` 不变才能在 Anki 里更新而不是重复。
- **目标数与内容不匹配**：内容撑不起目标数就少做，并说明；不要为凑数拆出“X 的英文是什么”这类卡（英文名放在 extra）。
- **其他学科**（细胞、遗传、植物生理）：同样的卡型和原则适用；把本仓库的 858/626 口径换成用户的考试口径。
