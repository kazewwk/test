# 新概念英语 Anki：全课程文字初版

本版为两册全部课组提供文字卡片，共13,165张卡。**这是文字制卡初版；尚未完成全部课件截图视觉复核、相关背图匹配和独立覆盖审计，不能视作原要求的严格全审成品。** 当前2课来源独审通过，其余未完成项逐课列在《未完成项目.csv》，具体待核记录96项列在《待核清单.csv》（包括暂未制成日常卡的待核源记录）。没有把资料下载、OCR解析或模型自报reading_complete当成独立审计通过。

## 导入

桌面Anki选择“文件→导入”，分别导入两份APKG。AnkiDroid可直接打开APKG导入；AnkiMobile可先桌面导入，再经AnkiWeb同步。图片已包含在包内，等待媒体同步完成即可离线显示；TTS使用设备英语语音，需设备安装对应英语语音。

## 牌组和标签

两个父牌组分别是“新概念英语第一册”和“新概念英语第二册”，各课为L001等子牌组，开篇放L000。课号三位补零。卡片均在子牌组中，父牌组不直接放卡。

`NCE::第一册::L001`等按课筛选，`类型::词汇/语法/句型/语音/课文/练习/拓展`按内容筛选；`考研大纲词`据ECDICT的ky标记。`待核`表示明确尚不能确定的知识或音标，请优先回看来源后再学习。未独审课程的初稿也可能需要后续修订。

先从每日10–20张新卡起步，先清到期复习，再逐步增加。已掌握的基础词可自行暂停；建议跟随课程进度学习子牌组。
