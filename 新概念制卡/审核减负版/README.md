## 首次导入

桌面 Anki“文件→导入”分别选择两份 APKG，并勾选**导入学习进度**，以保留选练卡的暂停状态；包内所有卡均无预设复习记录。AnkiDroid可打开APKG导入；若手机导入未保留暂停状态，可先在桌面导入，再经AnkiWeb同步。图片已包含，TTS使用设备英语语音。

## 已导入10月29日初版：保进度升级

先把各设备正常同步。在桌面Anki“工具→插件→从文件安装”选择[旧版保进度升级.ankiaddon](旧版保进度升级.ankiaddon?raw=true)，重启后在“工具→新概念：选择新版两册并保进度升级”同时选中两份新版APKG。

工具自动备份当前集合，逐笔记处理类型变更，导入新版，归档旧重复题并暂停选练。原卡ID、复习间隔和复习历史保留；原主卡的历史与间隔保留；新拆分的子卡作为新卡学习，不伪造过去复习记录。因保留历史，旧库里的归档实体卡不会删除，实际日常复习量会下降。

升级后若Anki提示完整同步，由这台已升级桌面上传，手机随后下载。备份和升级日志位于个人资料目录的 `nce-upgrade-backups/`。工具按官方Anki26.9.3后端实测；[旧版升级验证](旧版升级验证.json)保留检查结果。

## 使用

每册一个父牌组、各课一个子牌组；父牌组不直接放卡。按课号逐步学，不必一次开启所有课。`NCE::第一册::L001`等标签用于按来源课查找跨课归并知识；`类型::`用于筛内容，`考研大纲词`据ECDICT，`待核`内容先回看来源。选练暂停只是降低日常负担，可在需要时恢复。

首次可从每天10–20张新卡起步，先完成到期复习，再按实际负担调整。后续保留原牌组直接更新，不先删除旧牌组。
