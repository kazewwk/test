## 精简版说明（2026-11）

按上海大学 858 生物化学 2011–2022 年真题整理了[按章考点表](../上海大学858真题考点表.md)，据此对全部章节做了精简：

- **删减**：第 1–26 章由 2602 张减到 2192 张，删的是非关键步骤的逐步细节、物种特例、结构域和数值细节、自编数值变式和同一知识点的重复角度；真题考点、名词解释、关键酶与调节、标准计算、经典比较全部保留。
- **补缺**：真题考过而原卡没有直接训练的考点，新增 61 张卡，带 `补缺::真题` 标签。
- **标签**：直接对应真题考点的卡带 `真题::上大858` 和年份标签（如 `真题::上大858::2021`），可在 Anki 浏览器里按标签筛选优先复习；每张现行卡都带 `版本::精简2026-11`。
- **口径**：核心答案先按教材和真题答案的说法写，再括注更严格的说法。

**已经导入过旧版的**：直接重新导入新的 APKG（学习进度保留）。导入后在浏览器搜索 `deck:生化 -tag:版本::精简2026-11`，搜到的就是这次删掉的卡，全选后暂停或删除即可。

APKG 下载后导入 Anki。各章保留稳定、独立的笔记标识；已用原生 Anki 验证连续导入和重复导入。

闭卷练习的题目、答案及图片均包含在独立 HTML 中；下载保存后用浏览器打开，先作答再展开答案。这些完整题不进入日常 Anki 队列。

后续制卡默认将最终 APKG 和独立闭卷练习同步到本目录，并更新本表、提供 GitHub 下载链接。
