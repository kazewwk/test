第 1 题

论述戊糖磷酸途径的反应过程：分阶段写出各步反应的底物、酶、产物和辅因子，说明非氧化阶段的碳骨架转换及其与糖酵解的联系。

查看答案

① 概况。 途径在细胞溶胶中进行，起始物为6-磷酸葡糖，分为氧化阶段和非氧化阶段。

② 氧化阶段。 （1）6-磷酸葡糖脱氢酶以NADP⁺为电子受体，将6-磷酸葡糖氧化为6-磷酸葡糖酸-δ-内酯，生成NADPH；（2）内酯酶水解内酯为6-磷酸葡糖酸；（3）6-磷酸葡糖酸脱氢酶以NADP⁺为受体催化氧化脱羧，生成5-磷酸核酮糖、NADPH和CO₂（C1放出）。第1、3步自由能下降大，细胞内基本不可逆。小计：6-磷酸葡糖 + 2NADP⁺ + H₂O → 5-磷酸核酮糖 + 2NADPH + 2H⁺ + CO₂。

③ 异构与差向异构。 5-磷酸核酮糖异构酶经烯二醇中间产物生成醛糖5-磷酸核糖；5-磷酸核酮糖差向异构酶生成C3差向异构体5-磷酸木酮糖，因为转酮酶只接受C3构型同木酮糖的酮糖供体。

④ 转酮与转醛。 转酮酶（需TPP）：5-磷酸木酮糖 + 5-磷酸核糖 → 3-磷酸甘油醛 + 7-磷酸景天庚酮糖；转醛酶：7-磷酸景天庚酮糖 + 3-磷酸甘油醛 → 4-磷酸赤藓糖 + 6-磷酸果糖；转酮酶：5-磷酸木酮糖 + 4-磷酸赤藓糖 → 3-磷酸甘油醛 + 6-磷酸果糖。碳数为C5+C5→C3+C7、C7+C3→C4+C6、C5+C4→C3+C6，即3个五碳糖→2个六碳糖＋1个三碳糖；供体总是酮糖，受体总是醛糖。非氧化反应全部可逆。

⑤ 与糖酵解联系。 6-磷酸果糖和3-磷酸甘油醛都是糖酵解中间产物：6-磷酸果糖经磷酸葡糖异构酶回到6-磷酸葡糖；3-磷酸甘油醛可经糖异生酶合成6-磷酸果糖，或经糖酵解氧化为丙酮酸。因此途径既能循环产生NADPH，也能反向由己糖磷酸生成戊糖磷酸。

评分要点与来源
  • 细胞溶胶；G6P起始；两阶段
  • 氧化三步：G6PD→内酯，内酯酶→6-磷酸葡糖酸，6PGD氧化脱羧；NADP⁺
  • 第1、3步不可逆；氧化阶段小计2NADPH＋CO₂
  • 异构酶→R5P（烯二醇）；差向异构酶→Xu5P及原因
  • 两次转酮、一次转醛的底物与产物
  • 碳数转换3C5→2C6＋C3；酮糖供体/醛糖受体；可逆
  • F6P、GAP与糖酵解/糖异生衔接

第 2 题

习题7：戊糖磷酸途径受到怎样的调控？请从关键酶的调节和按细胞需要分配代谢流两方面论述。

查看答案

① 调控点。 6-磷酸葡糖脱氢酶催化的第一步脱氢实质上不可逆，是生理条件下的限速反应和重要调控点。

② NADP⁺/NADPH比值。 NADP⁺是该反应的电子受体，其水平是最重要的调控因子；NADPH与NADP⁺竞争活性部位，竞争性抑制6-磷酸葡糖脱氢酶和6-磷酸葡糖酸脱氢酶。营养充足大鼠肝胞液NADP⁺/NADPH约0.014（同条件NAD⁺/NADH约700），NADP⁺远低于NADPH，稍有升高即可激活酶，使NADPH生成与还原性生物合成的消耗偶联。NADPH积累时途径受抑，6-磷酸葡糖更多进入糖酵解；NADP⁺升高则进入本途径的流量增加。

③ 非氧化阶段可逆。 转酮酶、转醛酶反应可逆，使本途径与糖酵解按需要灵活联系。

④ 按需分配。 （1）5-磷酸核糖需要远超NADPH（如细胞分裂期）：糖酵解中间物经逆向非氧化反应生成5-磷酸核糖，5分子6-磷酸葡糖 + ATP → 6分子5-磷酸核糖 + ADP + H⁺；（2）二者平衡：以氧化阶段为主，6-磷酸葡糖 → 5-磷酸核糖 + 2NADPH + CO₂；（3）NADPH需要远超5-磷酸核糖（如脂肪组织合成脂肪酸）：5-磷酸核糖经转酮、转醛和糖异生再生6-磷酸葡糖，净式6-磷酸葡糖 + 12NADP⁺ + 7H₂O → 6CO₂ + 12NADPH + 12H⁺ + Pi；（4）此外，5-磷酸核糖经6-磷酸果糖、3-磷酸甘油醛进入糖酵解生成丙酮酸，同时得到ATP和NADPH。

评分要点与来源
  • G6PD第一步：不可逆、限速、调控点
  • NADP⁺最重要；NADPH竞争性抑制G6PD/6PGD
  • 比值0.014 vs 700；NADP⁺少量升高即激活，生成与消耗偶联
  • NADPH积累→G6P转入糖酵解；NADP⁺升高→PPP流量增加
  • 非氧化阶段可逆，灵活联系糖酵解

  • 情况3、4及其计量/产物

第 3 题

习题8：说明戊糖磷酸途径的生物学意义。

查看答案

① NADPH的主要来源。 NADPH在核糖C2′上比NADH多一个磷酸；NADH主要经呼吸链产生ATP，而NADPH在还原性生物合成中作氢负离子供体：肝、脂肪组织、授乳期乳腺合成脂肪酸，肝、肾上腺、性腺合成胆固醇和固醇类，核糖核苷酸还原为脱氧核糖核苷酸、光合作用中由CO₂合成葡萄糖也需要NADPH；它还用于抵消氧自由基损伤。

② 保护红细胞。 红细胞中本途径酶活性高。NADPH经谷胱甘肽还原酶维持GSH：维持蛋白质—SH和结构完整、防止膜脂被过氧化物氧化、使血红素铁保持Fe²⁺；眼球、角膜同样需要NADPH保护。G6PD遗传缺陷者红细胞NADPH不足，遇伯氨喹、磺胺、阿司匹林或蚕豆易发生溶血性贫血（黄疸、尿黑、血红蛋白下降）。

③ 戊糖及多种糖的来源。 5-磷酸核糖及其衍生物构成ATP、CoA、NAD⁺、FAD、RNA和DNA；骨髓、皮肤、小肠黏膜和癌细胞等快速增殖组织依赖本途径迅速供给。途径还提供三至七碳的不同结构糖分子，并为各种单糖的相互转变提供条件。

评分要点与来源
  • NADPH与NADH结构/功能区别；氢负离子供体
  • 需NADPH的过程与组织
  • 红细胞：GSH维持及三项作用
  • G6PD缺乏：氧化药物/蚕豆→溶血性贫血
  • 5-磷酸核糖构成的分子；快速增殖组织
  • C3～C7糖来源与单糖互变

第 4 题

习题2：用¹⁴C标记葡萄糖的C6原子，加入含戊糖磷酸途径的酶和辅助因子的体系中（设葡萄糖先磷酸化为6-磷酸葡糖进入途径），放射性标记将在何处出现？写出首轮追踪过程。

查看答案

① 氧化阶段。 6-磷酸葡糖C6 → 5-磷酸核酮糖C5；放出的CO₂来自C1，故首轮CO₂无标记；5-磷酸核糖、5-磷酸木酮糖均为C5带标记。

② 第一次转酮。 木酮糖C3～C5成为3-磷酸甘油醛C1～C3，甘油醛C3带标记；核糖C1～C5成为景天庚酮糖C3～C7，景天庚酮糖C7带标记。

③ 转醛。 3-磷酸甘油醛（C3带标记）接受景天庚酮糖C1～C3，成为6-磷酸果糖C4～C6，故6-磷酸果糖C6带标记；景天庚酮糖C4～C7成为4-磷酸赤藓糖，C4带标记。

④ 第二次转酮。 4-磷酸赤藓糖C1～C4成为6-磷酸果糖C3～C6，C6带标记；木酮糖C3～C5成为3-磷酸甘油醛，C3带标记。

⑤ 结论。 标记出现在6-磷酸果糖（及由其再生的6-磷酸葡糖）C6、3-磷酸甘油醛C3；中间物为戊糖C5、景天庚酮糖C7、赤藓糖C4；首轮不出现在CO₂中。

评分要点与来源
  • G6P C6→戊糖C5；CO₂来自C1，无标记
  • 第一次转酮：GAP C3、S7P C7带标记
  • 转醛：F6P C6、E4P C4带标记
  • 第二次转酮：F6P C6、GAP C3带标记
  • 结论：F6P/G6P C6与GAP C3；首轮CO₂无标记

第 5 题

习题3：用¹⁴C标记5-磷酸核糖的C1，加入含转酮酶、转醛酶、磷酸戊糖差向异构酶、磷酸戊糖异构酶和3-磷酸甘油醛的溶液中，4-磷酸赤藓糖和6-磷酸果糖中的放射性标记如何分布？

查看答案

① 戊糖互变。 异构酶和差向异构酶使5-磷酸核糖、5-磷酸核酮糖、5-磷酸木酮糖互变，三者均为C1带标记。

② 第一次转酮。 木酮糖C1—C2（C1带标记）转给核糖（C1带标记），生成C1、C3带标记的7-磷酸景天庚酮糖；同时生成的3-磷酸甘油醛（木酮糖C3～C5）无标记。

③ 转醛。 景天庚酮糖C1～C3转给无标记的3-磷酸甘油醛（加入的或上步生成的），生成C1、C3带标记的6-磷酸果糖；4-磷酸赤藓糖来自景天庚酮糖C4～C7，无标记。

④ 第二次转酮。 木酮糖C1—C2（C1带标记）转给无标记的赤藓糖，生成C1带标记的6-磷酸果糖。

⑤ 结论。 首轮：4-磷酸赤藓糖不带标记；6-磷酸果糖C1和C3带标记（C1来自两条反应，C3只来自转醛产物）。

评分要点与来源
  • 三种戊糖互变，均C1带标记
  • S7P C1、C3带标记；GAP无标记
  • 转醛：F6P C1、C3带标记；E4P无标记
  • 第二次转酮：F6P C1带标记
  • 结论：E4P无标记；F6P C1、C3带标记
