# 用户订阅接口的真实截图测试

仅使用一张样课 160.4 秒截图。原图与完整可见回答保留于本目录；不包含接口地址、密钥或隐藏推理内容。该结果不能解释为已用 API 重查整节课的 712 张截图。

| 请求模型 | 墙钟秒数 | 此图的观察 |
|---|---:|---|
| gpt-6.1-terra | 12.44 | 读出 5 个勾、圈选 +n、网、两处音标下划线 |
| gpt-6-luna | 17.20 | 同样读出以上关键项目，用于不确定项目复查 |
| gemini-3.8-flash-high | 31.96 | 此次将网读成两，并遗漏一处音标下划线 |

依据此样本，当前使用 Terra 主处理、Luna 在主回答不确定或不可用时复查／接替。它们读取画面，语音仍使用 Qwen3-ASR、ForcedAligner 和 Whisper。所有分歧保留原始候选并标记，不以视觉模型补写讲师未说的话。

用户已确认该接口使用现有订阅额度、没有额外按 Token 扣费。模型名为接口的请求与返回标识；单图表现不代表模型在所有视频上的总体精度。

新 Colab L4 上另一次实际生产适配器验证见 `colab_runtime_terra.json`：Terra 主回答约 14.93 秒，检测到不确定信息后确实调用 Luna；圈选候选不一致被保留为复核标记，不代表确定结论。
