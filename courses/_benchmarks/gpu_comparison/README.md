# 相同截图、相同模型精度的 GPU 测试

新概念第二册 L001 单词课，32 张相同原始截图。模型 Qwen3.5-9B，原生 BF16，无量化。

| 配置 | 批大小 | 纯推理时间 | 费率 | 按推理时间估算用量 |
|---|---:|---:|---:|---:|
| L4 | 4 | 316.19 秒 | 1.54 CU/h | 0.1353 CU |
| RTX PRO 6000 Blackwell（Colab G4） | 16 | 74.11 秒 | 8.90 CU/h | 0.1832 CU |

G4 测试期间账户余额减少 2.09 CU，包含同期 L4 用量，低于已授权 3 CU；测试实例已经释放，没有执行购买或充值。纯推理费用估算不包括安装、加载和等待时间，不能充当实际账单。

本次配置下 G4 更快，但单位样本推理费用更高，因此继续 L4。未穷举批大小或其他推理后端，也不以性能测试宣称识别准确率。模型输出中的疑点仍需按原始截图核验。
