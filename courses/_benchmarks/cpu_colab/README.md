8 vCPU、约 51 GiB RAM，AMD EPYC 7B12，账户实测费率 0.26 CU/h。固定模型版本与源文件摘要见 report.json。

报告将纯模型推理与首次加载墙钟时间分开。线性外推仅供费用判断，不能作为所有课的运行时间保证；完整项目还包含争议复查和画面处理。原始转写候选保留于 evidence/，可观察到 Whisper 遗漏英语例句，不能用模型一致率代替准确率。
