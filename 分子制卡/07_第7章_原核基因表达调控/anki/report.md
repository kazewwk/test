## 写法上的几个选择（看风格时留意）

1. **问答为主，不用填空**。制卡建议里列的“填空题会考”的数字（162/140/14、600/70、1:0.5:0.2、−60、+11）都写成了带条件、带一句推导的数值问答卡（020、012、008 等），而不是挖空；换个问法也能答。
2. **名词解释答案按“定义 + 关键特征 + 例/意义”三要素写**，粗体标得分词，复习时先口述再翻面对照。
3. **比较题用表格卡，问题面写明维度**（“从 A、B、C 六项比较……”），因为上大的名词解释和简答常以“比较 X 与 Y”出。每个成员另有自己的术语卡。
4. **图卡三种问法都有**：读图（图上没答案的 7-15、7-23、7-16 放正面）、默画（图上带标注的 7-4、7-20、7-22、7-9、7-11 放答案面，正面只有文字）。
5. **一个考点多角度**：弱化作用有术语（016）、对比（022、024）、读图（023）、数值（020）、机制（025）、实验（026）六个角度；间隔算法才能分辨你哪一块不熟。
6. **每张 extra 写来源（§/图号）、口径差异和易混提醒**，答错能回去查。

## 教材错误与口径问题的处理

- **“I⁻ 或 O⁺ 突变”应为 Oᶜ**（制卡建议已列出）：卡 015 按 Oᶜ 写，extra 注明原文笔误。
- **操纵区长度 26 bp / 21 bp 前后不一**：不出精确数字；卡 007 extra 注明两处说法，答题写“约 20 余 bp 的对称序列”。
- **β-半乳糖苷酶本底与诱导后数值前后不一**（1～2 个 vs “几个”，3000 vs >10⁵）：不出精确填空；卡 006 extra 记数量级（诱导后占总蛋白 6%～7%）。
- **图 7-16 下行标注“高葡萄糖 高 cAMP”是图上笔误**，应为低 cAMP：卡 011 extra 注明（制卡建议未列，阅图时发现）。
- **ONPG 被书中与 IPTG/TMG 并列为“高效诱导物/安慰性诱导物”**，但它实际是 β-半乳糖苷酶的发色底物：卡 004 答题举 IPTG，extra 说明。
- Markdown 文件里图 7-14/7-15 的图注与图片错位（标“图 7-15”的文件实为 CRP 弯曲 DNA 图），已核对原图后挑选，不影响卡片。
- 枯草杆菌 AT 蛋白基因 rtpA（原文误作 trpA）这一错误在本次范围内未制卡（TRAP/AT 属全面档），铺开时再按修正值写。

## Anki 导入与设置要点

1. Anki ≥ 23.10，双击 `分子_07_lac_trp预览.apkg` 或 File → Import；以后改卡重新打包再导入时，导入对话框把 **Update notes 设为 Always**，同 id 的卡会更新并保留进度。不要把文件改名为 collection.apkg。
2. 牌组是 `分子::07 原核基因表达调控`；整章做完后日常在顶层牌组 `分子` 复习让各章混排，子牌组只用于刚学完一章时聚焦。
3. 牌组选项开启 **FSRS**，学习步骤 `10m 30m`，**期望保留率 0.90** 起步，考前 2～3 周可升到 0.93～0.95 并勾选 Reschedule cards on change。
4. **最大间隔设为到考试天数的一半**：上大复试 3 月下旬，若 1 月初开始则约 80 天 → 设 40 天，保证每张卡考前至少再见一次。
5. 每日新卡：全章约 113 张、全书约 1090 张分 80 天 → 每天 15 张左右；本预览 31 张一两天即可过完。复习上限设高（9999），有积压先把新卡设 0。
6. 复习动作：看到问题先口述/默写完整答案再翻面对照粗体；默画卡（003、018）真的动笔画；表格卡先在脑子里填完再翻。Hard 是“答对但慢”，忘了必须按 Again。
7. 考前两周：建 filtered deck `tag:论述框架` 每天过一遍；`tag:第7章 tag:对比` 抓比较题；取消“Reschedule cards based on my answers”做预览模式。
8. 每周看一次 `tag:leech`，多半是卡写坏了（一卡多事实/问句含糊），先改写再拆。
