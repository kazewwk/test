# 生物考研 Anki 制卡
本版本按用户 2026-10-10 的完整覆盖要求修订。用户明确要求优先于本技能。参考其他工具的制卡方法不等于要求使用该工具；未明确要求时不生成 Obsidian 语法。
## 最高优先级
执行顺序为教材覆盖完整性与准确性、答案和知识联系完整性、清楚且可评分的提问、控制重复与复习负担。不以固定卡量、答案字数、统一要点数、节约输出或“一卡一个事实”牺牲前两项。默认全部 Basic，不自动反向、不批量挖空。
## 材料与逐项阅读
确认实际文件、版本、目录、范围、缺页、重复、模糊和损坏。考试年份、大纲、官方题型未提供时明确未提供，不猜测。区分教材印刷页码与 PDF 页序；无可靠页码用文件名、真实行号、段落编号或图表编号。
按教材原顺序，以连续完整章节或小节为批次。每批完整读取后再制作和核查。下载、哈希检查、标题、关键词、片段、OCR、缩略图及主题映射均不能证明全文或原图已审阅。逐段记录实际读取状态；未读取材料必须保持待处理。
阅读包含正文、定义、特征、分类依据、机制、过程、条件、调控、例外、比较、公式、数据、例子、实验、图题图注、表下注释、脚注、专栏、英文正文与拓展、章末总结及习题中的知识。
一个段落、表或图可能包含多个独立知识点，必须分别登记。重复可合并但保留所有来源对应关系；仅装饰、排版或没有新增知识的重复可不另制卡，并写具体理由。不得以低频、非重点、太细、不像考点为由删除有知识含义的材料。大纲和真题调整优先级而不缩减指定教材范围。
## 原意、条件与疑点
保留研究对象、原核／真核、物种、区室、阶段、方向、数量、实验条件、调控与例外；不删除“通常、可能、主要、仅在”等限定，不把相关写成因果，不将特定结论泛化。
核对术语、缩写、数字、单位、上下标、正负号、公式、化学计量、5′／3′及促进抑制。默认不补教材之外的事实。基于教材推导的问题明确标为“基于教材推导”，列前提及推导步骤；不得伪装直接表述。
识别歧义、缺失、内部冲突或疑似学术错误列入待核实表，记录原文与位置。未解决内容不作为确定事实导出；其余可信内容继续。可用实际读取的另一指定教材交叉核对，须同时保留来源与版本差异，不能凭印象纠错后宣称原书支持。
## 完整作答任务
一卡一个完整、明确、可评分任务，可包含服务于同一主题的紧密相关子问。该问题必要的定义、条件、过程、原因、结果与例外共同构成完整答案，不拆成必须拼接其他卡才能理解的短语卡。
拆分依据为知识与作答任务的自然边界。题目过大时缩小范围并把剩余知识明确分配给别的卡；不得删点缩短。过碎时合并。复杂机制和比较除局部题外设有明确范围、完整答案及评分结构的整合题，不问“概述本章”，不答“见上一张”。
答案不设统一字数或要点上限。定义说明本质、必要特征、范围和区别；机制讲清起始条件、参与者作用、顺序、步骤因果、结果及调控；比较使用统一维度并说明共同点、区别、条件和原因；分类说明依据、层级、特征和必要代表；计算包含前提、公式、步骤、单位和结果含义；实验包含问题、设计、处理与对照、指标、结果、证据推理及教材明确的限制。综合题形成能够实际复述和书面作答的连贯答案。
## 图片、表格与英文
逐张实际看原图，核对结构、标注、箭头、方向、连接、颜色、符号、坐标、单位、比例尺及图注；不能只读 OCR 或图注。逐项读取表格标题、行列、所有单元格、条件与附注。英文逐句理解，保留重要术语、教材全称和限定，与中文同等覆盖。
读图任务说明（需看图：具体结构、箭头或变量），真实图片直接嵌在对应学习卡中。要求看图作答放正面，机制解释放背面；不建独立图册凑数，不堆无关图。数据图答案解释观察、推理及结论条件。
无可用图时能改成完整文字题则改写；否则列待补图清单，不伪造媒体路径或遮挡卡。优先教材原图；必要且获用户授权时可用图像模型，必须实际复查全部学术关系，存疑重做或排除。不得声称绝对无误。
多栏OCR中的图注、字母与α／β等标签可能邻接错位。必须按实际图像、清楚的原标签及同资料交叉图核对对应关系，记录具体纠错证据；不能仅凭相邻文字、文件名或裁切顺序配对。
重要术语采用中文（English）。一张独立卡中缩写首次出现时给教材支持的中英文全称；Ras 等专名不臆造展开式。英文不泄露正面待回忆答案。
净结构反应图与实际活化底物、离去基团及酶催化路线分别核对，不能把净失水画法或图示能量条件推广到所有真实聚合步骤。数字的物理条件未给出时，可作明确题设的条件题；无条件泛化及未解决的图注口径冲突留待核实。
## 每张卡的结构
正面为完整、独立可理解的问题，必要子问限定回忆范围，不用指代不明的“它、上述”，不泄露答案。
背面必须包含：
完整答案：直接回答题干，保留必要解释、因果、条件与例外。
必答点：从完整答案中明确判断答对所需的内容，包括关键连接和决定正误的条件；不能把必考知识移到额外解释。
理解与联系：帮助理解和辨析；若含新增重要目标，应加入本题及评分或另设完整问题，不能将此栏当作覆盖藏匿处。
依据与来源：教材直接支持／基于教材推导，教材版本、章节、小节、真实定位及图表号。
唯一卡片 ID 和对应知识点 ID。
标签包含学科、章节、主题、任务类型，标签内部无空格，以一个半角空格分隔。
## 覆盖与验收
建立知识点覆盖表：教材位置｜具体知识点｜知识点 ID｜卡片 ID｜答案具体位置｜明确回忆要求｜必答点位置｜处理状态。每个独立知识点单独登记；一个答案段可对应多个点，但每点都能定位。
内容覆盖要求知识完整、准确且可追溯；回忆覆盖要求题目明确要求，且答案与评分纳入。不以来源栏、标签、附加阅读或卡背出现一次冒充回忆覆盖。
教材到卡片逐项查遗漏，卡片到教材逐张查无依据扩展、条件变化、来源错误、答案过短、因果断裂或模糊问题。检验是否只列名称、不解释作用；只写结果、删原因；只写步骤、缺连接；漏关键条件例外；依赖另一卡。问题先修复再导出。
覆盖比例以具体知识点为分母并说明分母范围；未读材料无法计算知识点总数，不能声称全书覆盖率。仍有缺口时不称全书无遗漏。脚本验证只能证明其检查项，不能证明语义或学术完全正确。
## 导出与持续推进
生成用户实际请求的文件。安卓用户交付内嵌引用媒体的 APKG，不要求操作媒体目录。配套 TSV 为 UTF-8、真实 Tab 三列 Front／Back／Tags，每行一条笔记，内部换行用 <br>，正确 HTML 转义，正式数据不含表头、Markdown、核查文字或占位卡。
回读核对列数、空字段、重复 ID、笔记数、媒体引用、HTML、实际普通卡数。原生 Anki 后端检验空集合和重复导入、牌组及缺图；按手机宽度查看显示，未在实体安卓测试就如实记录。
重制改变任务时使用新的版本与身份，记录旧题对应，不将旧进度强套在新任务。小改才保留身份并测试更新。
每批交付卡片、覆盖表、实际完成范围、卡数、缺口清单和下一起点；审计文件独立于导入数据。长任务持续推进，不以样例代替完整工作。上下文不足时停在完整卡边界，持久化最后教材位置、卡片 ID、未完成点及下批起点，沿用编号。
用户已授权的 GitHub 上传直接执行，验证远端文件。不得声称已写回无写入工具的云技能；可交付并上传可安装的修订技能包，说明实际修改位置。
